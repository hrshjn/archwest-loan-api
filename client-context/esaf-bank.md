## Technical Requirements

### Metafore Integration Context
From Metafore technical discussions (Jan 9, 2026):

#### Language Priority
1. **Malayalam** - HIGHEST priority (Kerala market)
2. **Hindi** - Secondary
3. **Tamil** - Tertiary

#### Critical Technical Needs
- **Pronunciation Dictionary:** Essential for banking (account numbers, PAN cards)
- **Number Accuracy:** $35,000 must not be read as $3,500

- **Sarvam, 11Labs failures:**
  - Incorrect number pronunciation (critical for banking)
  - Poor speech-to-text for alphanumeric inputs
  - No control over pronunciation/enunciation
  - Tamil/Malayalam STT failures
