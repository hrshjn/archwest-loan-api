## Critical Technical Requirements (Banking Use Cases)

### 1. Pronunciation Dictionary - ESSENTIAL
**Why:** Banking requires absolute number accuracy
- **Problem Previous Providers Had:** $35,000 read as $3,500
- **Requirement:** Context-dependent number reading (currency vs. account numbers)
- **Smallest Solution:** Pronunciation dictionary + SSML support
- **Status:** Configuring for LiveKit integration

### 2. Alphanumeric Accuracy
**Problem Previous Providers Had:** Poor STT for alphanumeric inputs
- 6-digit national ID + 4-digit PIN
- PAN card format (AAC9277M)
- Account numbers
- Transaction IDs

### 3. Multi-Language Support
**Priority Languages for Banking:**
1. **Malayalam** - Highest (Kerala banks, ESAF)
2. **Hindi** - High (pan-India)
3. **Tamil** - Medium
4. **Other regional** - As needed

### 4. LiveKit Integration
- Plugin available from Smallest
- Solves major implementation challenges
- Metafore can integrate easily
- Need to clarify pronunciation dictionary setup for LiveKit
