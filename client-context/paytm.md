## Technical Architecture

### Paytm's Current Voice Stack

**Telephony Layer:**
- **Inbound IVR:** JSCIP library → OpenSIP server → RTP proxy → JavaScript service
- **Outbound:** App-based calling (P4B app, Paytm app)
- **Integration Protocol:** WebSocket, SIP
- **Audio Codecs:** G711, Opus, G729, PCMA
- **Sampling Rates:** 8KHz, 24KHz, 48KHz

**Voice Processing:**
- **Current TTS:** Microsoft (production standard)
- **Current LLM:** Llama 70B for text bot
- **Audio Processing:** Upsampling, downsampling, anti-aliasing filter, transcoding, companding (mu-law, a-law)

**Platform Layer:**
- **Dashboard:** Analytics, post-call analytics, call logs, real-time transcripts
- **Campaign Management:** Audience upload, retries, scheduler
- **Knowledge Base:** Jinja templates for contextual prompts
